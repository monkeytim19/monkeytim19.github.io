**Authors:** Jun R. Lee, Sadegh Emani, Michael D. Hollins, Timothy Wong, Carlos V. Sanchez, Francesca Toni, Dekai Zhang, Adam Dejl

**DOI:** [10.1145/3715275.3732186](https://doi.org/10.1145/3715275.3732186)

We developed XAI-Units, an open-source Python package that evaluates different AI explanation methods using a unit-test-style benchmark. The package incorporates interoperability with the Captum library and supports custom feature attribution methods and evaluation metrics across tabular, text, and image data.
