**Authors:** Gholamali Aminian, Andrew Elliott, Tiger Li, Timothy Wong, Victor C. Dehon, Lukasz Szpruch, Carsten Maple, Christopher Read, Martin Brown, Gesine Reinert, Mo Mamouei

**DOI:** [10.48550/arXiv.2509.2371](https://doi.org/10.48550/arXiv.2509.2371)

We present FraudTransformer, a GPT-like model pre-trained from scratch on tabular payment transaction data using next-token prediction, with novel time-aware encodings. The model is fine-tuned for fraud detection and demonstrates competitive performance while detecting a distinct set of fraudulent cases compared to gradient boosting baselines.
