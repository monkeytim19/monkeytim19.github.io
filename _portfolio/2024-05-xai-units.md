**Duration:** Dec 2023 – May 2024  
**Repository:** [github.com/XAI-Units/xaiunits](https://github.com/XAI-Units/xaiunits)  
**Supervised by:** Prof. Francesca Toni and PhD students, Imperial College London

Developed as a group of six under academic supervision, resulting in a conference paper accepted to ACM FAccT '25.

- Developed an open-source Python package *XAI-Units* for evaluating different AI explanation methods
- Created a pipeline for benchmarking feature attribution methods and streamlined the evaluation process
- Incorporated interoperability with the Captum package and any custom feature attribution methods or evaluation metrics
- Crafted neural network models and synthetic data generators across tabular, text, and image modalities

**Tools:** Python, PyTorch, Captum
